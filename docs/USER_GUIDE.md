# Руководство пользователя

## Добавление товаров

Просто отправьте боту сообщение. Одна непустая строка всегда означает одну позицию:

```text
Молоко 2 л
Хлеб
Сыр, 300 г
```

Запятые не разделяют товары. За одно сообщение принимается до 50 строк, каждая длиной до 120
символов. Можно также нажать «➕ Добавить» и отправлять товары по одному, не закрывая режим ввода.

В конце названия бот распознаёт количество с единицами `шт`, `кг`, `г`, `л`, `мл`, `уп`, `бут` и
`бан`. Если единица не указана, используется одна штука. Активные дубликаты с одинаковым названием и
единицей объединяются, их количество складывается.

## Работа со списком

- Нажмите широкую строку товара, чтобы отметить его купленным или вернуть в активные.
- Через «🛠 Управление товарами» меняются название, количество, единица, категория и цены.
- Плановая и фактическая цена задаются в рублях за всю позицию.
- Бюджет относится ко всему открытому списку.
- Удаление позиции, очистка купленного и закрытие списка требуют подтверждения.
- Кнопка отмены возвращает только последнее изменение в течение 30 минут; любое следующее изменение
  делает предыдущую отмену недоступной.

## Повторные закупки

Частые товары можно сохранять в избранное. Текущий набор товаров можно сохранить как шаблон и затем
добавить снова. Закрытые списки остаются в истории; открыть старый список повторно можно, только если
другого открытого списка нет.

## Уведомления и напоминания

Каждый пользователь выбирает собственный уровень уведомлений: все изменения, только важные или без
дополнительных сообщений. Общий экран списка синхронизируется независимо от этого выбора.

Доступны фиксированные напоминания: каждый день в 18:00, в пятницу в 18:00 либо в субботу в 10:00.
Время рассчитывается по `BOT_TIMEZONE`, заданному владельцем установки.

## Модель доступа

Бот работает только в личных чатах. Все ID из `ALLOWED_USER_IDS` видят один общий список и имеют
одинаковые права. Пользователь вне белого списка не получает доступ к данным.
