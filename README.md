**KupimVmeste** — приватный Telegram-бот для семьи, пары или небольшой команды. Пользователи ведут один
общий список, отправляют товары обычными сообщениями, отмечают покупки и синхронно видят изменения.
Данные хранятся локально в SQLite, а доступ разрешён только Telegram ID из белого списка.

## Возможности

- один товар или многострочный список в одном сообщении;
- одна широкая кнопка товара без перекрывающих название элементов;
- количество и единицы измерения, включая распознавание записей вроде `Молоко 2 л`;
- объединение повторных активных товаров с увеличением количества;
- автоматические категории и сортировка списка;
- плановые и фактические цены, бюджет всей закупки;
- избранные товары и шаблоны повторяющихся закупок;
- отмена последнего изменения с сохранением после перезапуска;
- история закрытых списков и повторное открытие;
- личные настройки уведомлений и регулярных напоминаний;
- доступ только из приватных чатов и только для разрешённых пользователей;
- горячие локальные резервные копии SQLite с проверкой целостности;
- hardened systemd units для самостоятельного размещения на Linux-сервере.

## Приватность и ограничения

- одна установка обслуживает один общий workspace и один открытый список;
- пользователей может быть сколько угодно, но каждый ID нужно явно добавить в `ALLOWED_USER_IDS`;
- у всех разрешённых пользователей одинаковые права на общий список;
- поддерживаются только личные чаты с ботом, группы и публичный доступ отклоняются;
- приложение запускается одним процессом в режиме Telegram long polling;
- цены задаются в рублях за всю позицию, валюта сейчас не настраивается;
- напоминания имеют фиксированные варианты: ежедневно в 18:00, в пятницу в 18:00 или в субботу
  в 10:00 в часовом поясе `BOT_TIMEZONE`;
- отменить можно только последнее изменение, не позднее 30 минут и пока список не был изменён снова.

## Как это выглядит для пользователя

1. Отправьте один товар или несколько строк:

   ```text
   Молоко 2 л
   Хлеб
   Сыр, 300 г
   ```

2. Бот создаст или обновит общий список. Каждая непустая строка обрабатывается отдельно, а одинаковые
   активные товары объединяются.
3. Нажмите широкую строку товара, чтобы отметить его купленным.
4. Откройте **🛠 Управление товарами**, чтобы изменить название, количество, единицу, категорию или
   цену.
5. После закупки закройте список — он останется в истории.

За одно сообщение принимается до 50 непустых строк, длина одной позиции — до 120 символов.
Распознаются единицы `шт`, `кг`, `г`, `л`, `мл`, `уп`, `бут` и `бан`; запятая внутри строки не
разделяет товары. Подробные сценарии собраны в [руководстве пользователя](docs/USER_GUIDE.md).

## Требования

- Python 3.11 или новее;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather);
- числовые Telegram ID пользователей, которым разрешён доступ;
- системная база часовых поясов для выбранного `BOT_TIMEZONE`;
- Linux с systemd — только для приложенных production units.

## Быстрый запуск

```bash
git clone https://github.com/Dosash/KupimVmeste.git kupim-vmeste
cd kupim-vmeste

python3 -m venv .venv
.venv/bin/pip install .
cp .env.example .env
```

Заполните `.env`, затем экспортируйте переменные и проверьте соединение:

```bash
set -a
. ./.env
set +a

.venv/bin/python -m app.main --check
.venv/bin/python -m app.main
```

Файл `.env` не загружается приложением автоматически и исключён из Git. В production используйте
root-only environment file из инструкции по systemd.

## Конфигурация

| Переменная | Обязательна | Пример | Назначение |
|---|---:|---|---|
| `BOT_TOKEN` | да | `replace-with-token-from-botfather` | Секретный токен Telegram-бота |
| `ALLOWED_USER_IDS` | да | `111111111,222222222` | Разрешённые Telegram ID через запятую |
| `DATABASE_PATH` | нет | `./data/shopping_list.sqlite3` | Путь к SQLite; для systemd используется `/var/lib/shopping-list-bot/...` |
| `BOT_TIMEZONE` | нет | `Europe/Moscow` | Часовой пояс напоминаний, IANA name |
| `LOG_LEVEL` | нет | `INFO` | Уровень журналирования Python |

Бот не имеет публичного режима: пустой `ALLOWED_USER_IDS` считается ошибкой конфигурации. Групповые
чаты также отклоняются.

## Безопасность и приватность

- Никогда не коммитьте токен, `.env`, базу, бэкапы или production-логи.
- При утечке токена немедленно перевыпустите его через BotFather.
- Содержимое списков, Telegram ID и отображаемые имена хранятся локально в SQLite. При этом Telegram
  по-прежнему обрабатывает сообщения, отправленные боту.
- Локальные бэкапы на том же сервере не защищают от потери диска — копируйте их во внешнее хранилище.
