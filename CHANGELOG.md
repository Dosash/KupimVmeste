# Changelog

Все заметные изменения проекта фиксируются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют Semantic Versioning.

## [1.0.0] — 2026-08-21

### Добавлено

- общий приватный список для разрешённых Telegram-пользователей;
- добавление одного товара и многострочного списка, где каждая строка — отдельная позиция;
- количества, единицы, категории, цены и бюджет;
- избранное, шаблоны, история, отмена последнего действия и личные напоминания;
- синхронизация экранов, пагинация и защита от устаревших кнопок;
- SQLite-миграции, проверяемые горячие локальные копии и hardened systemd units;
- тесты, Ruff, GitHub Actions, Dependabot и документация для самостоятельного размещения.
